# Historical planning documents

These files describe ThetOS **as originally planned**, not as it was built:

- `roadmap.md` — the original six-phase development plan (Phase 0 sanity check through Phase 6 thesis submission), with per-phase gatekeepers.
- `phase2_hardware_port.md` — the Phase 2 (hardware port) implementation guide.
- `phase3_minimal_kernel.md` — the Phase 3 (minimal kernel & scheduler) implementation guide.

They are kept for the thesis narrative — what was intended, and how the work was structured. **They are superseded and are not current documentation.**

For the delivered v1.0.0 design:

- [`../scope.md`](../scope.md) — what v1.0.0 delivers, what is deferred, and the authoritative architecture boundaries.
- [`../decisions/`](../decisions/) — the architecture decision records (rationale + alternatives).
- [`../runbooks/`](../runbooks/) — reproducible hardware-validation procedures.

The gatekeeper methodology described in `roadmap.md` was followed and remains part of how the project is validated; the runbooks are its living form.
